# Node classification on the OGBN-Arxiv citation graph using GCN and GAT models.

## Quick start (local)

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the notebooks in order
Open Jupyter and execute each notebook sequentially from the `notebooks/` directory:

```bash
python -m jupyter notebook
```

| # | Notebook | Output |
|---|----------|--------|
| 01 | `01_tensor_fundamentals.ipynb` | Tensor operations demo |
| 02 | `02_graph_representation_analysis.ipynb` | Graph stats, subgraph plot, degree dist → `results/graph_analysis/` |
| 03 | `03_data_preparation.ipynb` | Processed tensors → `data/processed/` |
| 04 | `04_gcn_model.ipynb` | GCN checkpoint → `models/best_gcn.pt`, training history → `results/training/` |
| 05 | `05_gat_model.ipynb` | GAT checkpoint → `models/best_gat.pt`, training history → `results/training/` |
| 06 | `06_training_optimization.ipynb` | Hyperparameter trial table → `results/training/` |
| 07 | `07_model_evaluation.ipynb` | Metrics CSV, confusion matrices → `results/evaluation/` |
| 08 | `08_explainability_embeddings.ipynb` | PCA/t-SNE plots → `results/explainability/` |

> **Note:** Notebooks 04 and 05 must run before 07 and 08 (model checkpoints required).

### 3. Launch the dashboard
```bash
# Option A – convenience script
python run_dashboard.py

# Option B – directly
python -m streamlit run dashboard/app.py
```

The dashboard reads the CSV and image files generated by the notebooks and displays them interactively.

### 4. Build the PDF report template
```bash
python tmp_build_report.py
```
This generates `report/CCS4354_Technical_Report.pdf` — a blank template to fill with your verified results.

## Project flow

1. Tensor operations and GPU demonstration
2. Graph structure, degree, density, components, and sampled visualization
3. Dataset preparation and official OGB split export
4. GCN model development and training
5. GAT model development and training
6. Reproducible training and hyperparameter optimisation
7. Evaluation and comparison (accuracy, precision, recall, F1)
8. Embedding and neighbourhood explainability (PCA, t-SNE, attention)

## Data note

The first notebook that loads data (02 or 03) will download **OGBN-Arxiv** (~700 MB) automatically into `data/raw/ogbn_arxiv/`. Processed tensors, figures, metrics, and model checkpoints are generated by the notebooks and are excluded from Git.

## Integrity note

All recorded figures and metrics must be generated from your own executed experiments. The report and slides are templates until you add your verified results.
